# L'application Ti'Cagou Parents

[← Sommaire](README.md) · Mise en route du portail : [08-portail-nouvelle-creche.md](08-portail-nouvelle-creche.md) ·
Fiche à imprimer pour les familles : [18-guide-parents.md](18-guide-parents.md)

Les familles ont deux façons d'utiliser le portail, **au choix** :

- l'application **Ti'Cagou Parents** (App Store, Google Play) : notifications fiables sur iPhone, connexion par code ;
- la **PWA** dans le navigateur, comme avant (lien reçu par e-mail, ajout à l'écran d'accueil).

Le contenu est le même : journée, photos et vidéos, messages, actualités, absences et retards, demandes d'accueil,
factures, documents à signer.

## 1. Se connecter

1. Le parent installe Ti'Cagou Parents et tape **l'adresse e-mail donnée à la crèche**.
2. Il reçoit un e-mail avec un **code à 6 chiffres** (valable 15 minutes) et le tape dans l'application.

Rien ne s'affiche ? L'adresse n'est pas celle connue de la crèche, ou le portail n'est pas encore ouvert pour cette
famille : vérifiez la fiche famille (onglet Journée et portail).

## 2. Les notifications

À la première ouverture, ou dans **Mon compte › Notifications** : photos, messages, actualités, documents à signer,
factures (décochées au départ). Aucune information de santé, aucun texte de message : « Nouvelle photo de Maëlys »,
« Nouveau message de la crèche ».

## 3. Verrouiller l'application

**Mon compte › Verrouiller l'application** : Face ID, empreinte ou code du téléphone à chaque ouverture. Désactivé au
départ.

## 4. Supprimer son compte

**Mon compte › Supprimer mon compte**, puis le code reçu par e-mail :

- l'accès au portail, les sessions et les notifications du parent sont effacés tout de suite ;
- la crèche reçoit un message dans Messages : « Demande automatique : ce parent a supprimé son compte… » ;
- **la crèche décide pour le dossier** de la famille (export, puis effacement depuis la fiche d’un enfant › Famille, en respectant les durées de conservation des
  factures).

Le parent ne peut plus se connecter tant que la crèche ne modifie pas sa fiche ou ne le réinvite pas.

## 5. Dépannage

| Ce que voit le parent | Que faire |
|---|---|
| Pas d'e-mail | Vérifier les indésirables ; vérifier l'adresse sur la fiche famille ; attendre 15 minutes avant de redemander. |
| « Code incorrect » | Retaper le dernier code reçu ; après 5 essais, redemander un e-mail. |
| « Votre accès a été retiré par la crèche » | La famille n'a plus d'accès : la crèche le rouvre depuis la fiche. |
| Photos qui ne s'affichent pas | Fermer et rouvrir l'application (le droit de voir les photos se renouvelle). |
| Pas de notification | Mon compte › Notifications, puis réglages du téléphone. |
