# Ti'Cagou dans la poche — argumentaire des applications

[← Wiki](../wiki/README.md) · Démonstration : [demonstrations.md › Démonstration mobile](demonstrations.md#démonstration-mobile)

## En une phrase

**Toute la crèche dans la poche de la directrice, une tablette d'accueil qui ne sort pas de Ti'Cagou, et une vraie
application pour les familles — comprises dans l'abonnement.**

## Pour qui, quoi

| Application | Pour qui | Ce qu'elle change |
|---|---|---|
| **Ti'Cagou Direction** (iPhone, Android) | directrice, adjointe, gestionnaire, comptable | l'encadrement et les présences en direct où qu'elle soit ; les départs bloqués validés à distance ; les alertes qui comptent |
| **Ti'Cagou Pointage** (tablette Android) | l'équipe à l'accueil | une borne qui ne sort pas de Ti'Cagou (mode kiosque), qui continue sans internet |
| **Ti'Cagou Parents** (iPhone, Android) | les familles | la journée de l'enfant, les photos, les messages ; notifications fiables sur iPhone |

## Les arguments

1. **« Vous n'êtes pas à la crèche ? Elle vous prévient. »** Encadrement insuffisant plus de 5 minutes, sauvegarde en
   échec, tablette hors connexion : une notification, jamais d'information de santé dedans.
2. **« Le grand-oncle est à l'accueil et vous êtes en rendez-vous ? »** L'équipe demande votre accord depuis la tablette ;
   vous voyez l'enfant, ses allergies, qui est venu, si sa pièce d'identité a été vue ; vous autorisez ou refusez avec
   un motif. Tout est tracé. Le départ d'un enfant reste bloqué tant que la direction n'a pas décidé.
3. **Le même logiciel partout.** Pas une application « allégée » : les mêmes écrans, adaptés au téléphone. Ce que vous
   apprenez au bureau vaut sur le téléphone.
4. **Sécurité de niveau données de santé.** Face ID à chaque ouverture, double authentification, téléphone perdu retiré
   en deux clics, rien de sauvegardé dans le cloud d'Apple ou de Google.
5. **Compris dans l'abonnement.** Aucune place de PC prise par un téléphone (10 téléphones par crèche), aucun achat dans
   l'application.
6. **Une tablette qui reste à sa place.** Mode kiosque Android : pas de YouTube à l'accueil, l'écran reste allumé, la
   tablette redémarre sur le pointage. Coupure d'internet : on continue de pointer.
7. **Les familles sur le store.** « Ti'Cagou Parents » s'installe comme n'importe quelle application ; connexion par code
   reçu par e-mail, sans mot de passe ; suppression du compte possible depuis l'application.

## Objections fréquentes

| Objection | Réponse |
|---|---|
| « Je ne veux pas être dérangée le soir. » | Chaque alerte se coupe dans Plus › Notifications, et le téléphone garde ses réglages « Ne pas déranger ». |
| « Et si je perds mon téléphone ? » | Il est verrouillé par Face ID ; on le retire depuis l'ordinateur, il est déconnecté en 15 minutes. |
| « Nos tablettes sont des iPad. » | Le pointage marche dans le navigateur de l'iPad, comme aujourd'hui ; le mode kiosque est réservé à Android. |
| « Les parents ont déjà l'application web. » | Elle reste ; l'application des stores ajoute des notifications fiables sur iPhone et une installation familière. |
| « Combien ça coûte en plus ? » | Rien : comprises dans l'abonnement Ti'Cagou (15 000 F HT par mois). |

## Chiffres à donner

- 3 applications, 1 seul logiciel ; 0 F de plus.
- 10 téléphones de direction par crèche, sans place de PC.
- 5 minutes : délai avant l'alerte d'encadrement ; 15 minutes : délai maximum pour qu'un téléphone retiré soit coupé.
