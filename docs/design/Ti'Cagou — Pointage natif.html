Ti'Cagou Pointage — application native de la tablette

Phase 1 du plan. L’écran de pointage lui-même ne change pas (maquette Pointage tablette accueil) : cette maquette couvre ce que l’application native ajoute — appairage par scan QR, mode kiosque, état hors connexion, version trop ancienne. Tablette Android 11 pouces, paysage, 1 180 × 820.

Rappels
  • Le pointage n’est jamais bloqué par l’application : ni hors connexion, ni par une version trop ancienne (ADR 0027).
  • File d’attente et instantané du jour chiffrés, clé dans le Keystore matériel de la tablette (ADR 0023, 0024).
  • Santé visible sur chaque carte (allergie, PAI, régime), comme aujourd’hui.
  • iPad : Accès guidé (réglage d’iPadOS) à la place du mode kiosque Android — décision 5 du plan à trancher.
Écarts avec la maquette existante : nouveau bouton « Scanner le QR » à l’appairage (la saisie du code reste) ; nouvel indicateur « Mode kiosque » dans la barre ; le bandeau hors connexion compte désormais les pointages en attente.

P1 à P3 · Appairage par scan du QR

Le PC du bureau affiche le QR d’appairage (Paramètres › Postes › Ajouter une tablette, ADR 0008). Il contient l’adresse de la crèche et le code : l’application n’a rien d’autre à demander.
