Ti'Cagou Direction — téléphone

Maquettes des applications mobiles. Même application que le navigateur de l'ordinateur (un seul code React, ADR 0023) : ces écrans sont la largeur « téléphone » (moins de 640 px) des pages existantes. Données de démonstration : Les P'tits Niaoulis (Dumbéa), directrice Nathalie Kaloï. iPhone 390 × 844.

Principes
  • Navigation basse à 5 entrées selon le rôle : DIRECTION et EDUCATRICE → Accueil, Présences, Enfants, Messages, Plus ; COMPTABILITE → Accueil, Facturation, Statistiques, Inscriptions, Plus ; CUISINE → Accueil, Repas, Enfants, Plus. « Plus » liste toutes les autres rubriques du menu latéral (même ordre, mêmes rubriques masquables, ADR 0022).
  • Les informations de santé (allergies, PAI, régime) restent visibles partout où l'enfant apparaît : pastille rouge dans les listes, bandeau en tête de la fiche, rappel dans les feuilles d'action.
  • Les dialogues deviennent des feuilles qui montent du bas ; les actions principales restent au pouce (barre basse).
  • Montants en F CFA (XPF), sans décimale ; dates JJ/MM/AAAA ; heure de Nouméa.
Écarts avec les maquettes existantes (à valider)
  • Le menu latéral du bureau devient une barre basse + « Plus » sur téléphone ; la recherche globale (Ctrl K) devient l'icône loupe de la barre du haut.
  • Le tableau de bord « matinée type » est réduit à quatre blocs empilés (encadrement, présences, à traiter, repas) ; les graphiques de la semaine restent sur tablette et ordinateur.
  • Nouveaux écrans sans équivalent bureau : choix de la crèche, verrouillage Face ID, mise à jour requise, réglage des notifications.

A. Premier lancement : crèche, connexion, double authentification, verrouillage

ADR 0024 et 0025. La crèche se choisit une fois (QR, code ou adresse) ; la connexion garde le mot de passe + code TOTP ; le verrouillage Face ID / empreinte est obligatoire avant de garder la session 30 jours.
