Ti'Cagou Parents — compléments pour l’application des stores

Phase 1 du plan. Complète app parents mobile (connexion, fil de la journée, messages, absences, factures, documents), qui reste la référence et n’est pas modifiée. Écrans ajoutés pour l’application iOS / Android : accueil, connexion par code, autorisation des notifications, verrouillage, suppression du compte. Famille de démonstration : Anne Poédi, enfants Tom et Léna.

Écarts à valider
  • Dans l’application, la connexion se fait par code reçu par e-mail (6 chiffres) : le lien magique ouvrirait le navigateur, pas l’application. La PWA garde le lien.
  • La maquette existante montre un mot de passe ; le portail réel utilise lien ou code par e-mail (pas de mot de passe). Ces compléments suivent le portail réel.
  • Supprimer mon compte efface tout de suite l’accès au portail (adresse, sessions, appareils, notifications) et prévient la crèche. Les données tenues par la crèche (dossier, factures) ne sont pas effacées par le parent : la crèche les purge selon ses obligations (ordre PURGE_FAMILY existant, déclenché par la direction). Le plan disait « branchée sur PURGE_FAMILY » : à confirmer.
